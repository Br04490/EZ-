# Optional guardian-approved spoken dialogue files

No actual child voice recordings have been provided. Current game uses browser speech synthesis as a fallback.

To use real approved clips, upload them to `ezra/` or `lennox/` folders here and configure the clip IDs in `src/voice-clips.mjs`.
Clip ID examples: Ezra `green-ez-money`, `lets-hoop`, `bucket-total-5`; Lennox `countdown-5` ... `countdown-1`, `sister-01` ... `sister-15`.
The uploaded original songs are music tracks, **not** isolated dialogue audio files.
